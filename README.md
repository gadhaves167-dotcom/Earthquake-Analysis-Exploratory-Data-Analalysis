# 🌍 Earthquake Analysis using Exploratory Data Analysis (EDA)

## 📌 Project Overview

The **Earthquake-Analysis** project focuses on analyzing global earthquake data using Exploratory Data Analysis (EDA) techniques. The main objective is to extract meaningful insights, identify patterns, and understand trends related to earthquake occurrences across different regions, magnitudes, and time periods.

This project uses statistical analysis and data visualization techniques to better understand seismic activity and its characteristics.

---

## 🎯 Objectives

- Analyze earthquake frequency over time  
- Study magnitude distribution patterns  
- Identify high-risk geographic regions  
- Examine depth vs magnitude relationships  
- Detect trends and anomalies in seismic activity  
- Visualize earthquake occurrences using charts and maps  

---

## 📊 Dataset Description

The dataset contains earthquake records with the following attributes:

- **Date & Time** – Occurrence timestamp  
- **Latitude & Longitude** – Geographic coordinates  
- **Depth** – Depth of earthquake (in km)  
- **Magnitude** – Earthquake intensity  
- **Location/Region** – Place of occurrence
